BLACKLINE CAD · ONLINE 2D CAD

Draw 2D floor plans online in your browser

Blackline CAD (CAD2D) is an independent browser-based drafting prototype for students, architects and people learning technical drawing. Start drafting without installing desktop CAD software.

Open the 2D CAD editor

What can you draw?

Experiment with lines, polylines, rectangles and circles; organize objects in layers; create dimensions; draw and test wall tools; and save a drawing project. PDF and DXF export are available for compatible basic drawings.

For a first exercise, use a simple room or floor-plan sketch to check dimensions, snaps and editing behavior.

A beginner's floor-plan exercise

  1. Open Blackline CAD and choose drawing units.
  2. Draw the room outline with a known width and length.
  3. Place additional lines on separate layers and add dimensions.
  4. Save your project; export PDF or DXF and compare the resulting measurements.

Is this AutoCAD in a browser?

No. Blackline CAD is an independent application and is not affiliated with Autodesk. It does not reproduce all AutoCAD features or provide direct DWG import. It is intended for exploratory drafting and learning, rather than as a full production CAD replacement.

This software remains a prototype. DXF import supports only part of the 2D format; some editing tools require further testing. Verify exported files in another CAD application before any professional use.

For students and instructors

Teachers can use a simple measurement-and-layer exercise to evaluate the browser-based workflow. The academic introduction and command reference provide additional context. A sample house-plan exercise is also available in Spanish.

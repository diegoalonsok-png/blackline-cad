Polygon / Hatch / Table

POLYGON: center, then vertex. HATCH: select closed boundaries (polygon, polyline, rectangle or circle). TABLE: choose insertion point to draw an editable grid and cell text. All geometry is 1:1.

Object color / CAD properties

Select entities before applying a color. Explicit object colors are saved in the project and exported to DXF, SVG and PDF.

Advanced Modify

PEDIT: select exactly one unlocked polyline first. Vertex numbers begin at 1. Move/insert: click the target model coordinate or enter exact X,Y in COMMAND. Insert adds a vertex after the selected vertex.

EXTEND: pick a LINE near the end to extend toward a crossing boundary. JOIN: select connected lines. EXPLODE: selected polylines and rectangles. ARRAY: duplicates selected elements at exact model distances.

Dimensions / Annotation

Named DIMSTYLE presets stay inside this drawing and are included in CADJSON backups.

Linear: specify two reference points and the dimension-line position. Radius/diameter: click a circle, then text placement. Angular: vertex, first ray, second ray. Model values remain 1:1; arrow sizes use model units.

Modify geometry

OFFSET: choose a line, then click the target side. For circles choose inside/outside. CHAMFER and FILLET: select two straight line segments meeting at a corner, or whose ends can be extended to one. Enter distances in model units. TRIM operates on crossing straight segments.

Text / Typography
Aa Bb 123 · CAD2D

Place: click in model space. Apply: select one or more text objects first. Fonts use installed system families. DXF stores a text style reference; PDF uses standard fallback fonts, so some appearances may differ.

CAD2D — Quick start

Drawing

Click Line and click two points; repeat; Enter finishes.

Polyline connects points; Enter or double click finishes.

Circle: center then radius point.

Text: click the insertion point, type text in the prompt.

Coordinates can be entered in the command line.

Editing and navigation

Select with a click or drag left to right for a BLUE enclosed window; drag right to left for a GREEN crossing window. Use Shift to add objects. Borrar / Erase or Delete removes selected entities.

Hold Shift to select multiple entities.

Use Move, Copy, Rotate, Scale and Mirror on selected entities.

Mouse wheel zooms, middle mouse pans.

Space + left drag pans; Esc cancels.

Output

Export DXF R2000 (AC1015).

Import standard ASCII DXF entities (basic 2D types).

Save/Open native project JSON to preserve editing state.

Vector PDF at ISO, US or custom page size.

Accuracy

Coordinates are stored numerically, not in pixels.

Unit selection converts existing geometry to preserve physical size.

SNAP follows the selected grid spacing.

OSNAP recognizes endpoints, midpoints and centers.

This is a browser-based CAD prototype, not a full AutoCAD-compatible engine. For production use, test DXF interchange, plotting, and dimensions against professional software before relying on them for construction documents.

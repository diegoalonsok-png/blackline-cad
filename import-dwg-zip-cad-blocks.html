Import DWG and DXF CAD blocks from ZIP

If your CAD symbols are organized in folders and ZIP archives, select the archive in the CAD2D3D gallery. The importer reads supported drawings within the compressed file.

Launch CAD2D3D

Import workflow

Open the gallery, choose Import ZIP / DWG / DXF, and select one or more archives. Specify the units for drawings that do not declare them only if you know the correct units. Start the import.

Read the results

The progress counter distinguishes processed files, new blocks, duplicates and rejected drawings. DWG conversion does not support every entity; inspect errors and compare the imported result to the source.

Storage and limits

Import runs locally and accepted blocks are stored in the browser. Supported classic ZIP archives can be up to 256 MiB, with additional size and nesting limits. Always keep your source collection.

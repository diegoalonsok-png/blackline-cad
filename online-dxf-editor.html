Open DWG files and edit 2D DXF drawings online

CAD2D3D by Blackline is a browser-based 2D drafting editor. It supports editing compatible DXF drawings, layers and dimensions, and includes a local browser-based DWG conversion tool for supported files. The editor is an independently developed product.

Launch the online CAD editor

How to work with a DXF drawing

  1. Open Blackline CAD and select a supported DXF file, or use the local DWG to DXF conversion tool for a compatible drawing.
  2. Check the file's drawing units and measure an existing line of known length before editing.
  3. Use line, polyline, circle, dimension and layer tools to edit the supported entities.
  4. Save a project copy; export to DXF and reopen it in another CAD application to check geometry and units.

Download a sample DXF and verify 1:1 model scale

Use this Blackline sample DXF file to test drawing exchange before importing a professional project. It contains two lines measuring 10 m and 4 m, and a circle with a 1 m radius, on two layers, with drawing units declared in meters (DXF R2000).

  1. Download the sample, launch the editor and open a copy.
  2. Measure the horizontal line: it should be 10 m. The vertical line should measure 4 m.
  3. Inspect the CHECK-1TO1 and WALLS layers and check the circle radius.
  4. Export a new DXF, reopen it and repeat the checks. Resolve any discrepancies before relying on the result for construction documents.

This exercise checks basic entities and drawing units; it does not certify universal DXF compatibility. For a plotting test, a 10 m model line should measure 100 mm on paper at 1:100.

What file compatibility means

DXF is an exchange format, but not every DXF uses only basic 2D entities. Blackline CAD supports a limited set of common ASCII DXF geometry. Some imports may omit advanced blocks, xrefs, splines, nonstandard hatches, layouts or proxy objects. Imported drawings with ambiguous units need manual verification.

How DWG works: The remote conversion service is disabled. Try the local browser converter for supported DWG files. Some objects may not transfer; verify geometry, dimensions and units before relying on the result. Preserve your original file.

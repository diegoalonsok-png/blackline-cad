Open and edit compatible DXF drawings online

Blackline CAD (CAD2D) is a browser-based 2D drafting editor. You can work with simple geometry, drawing layers, dimensions and compatible DXF files without installing a desktop CAD program. The editor is an independent developing product, not AutoCAD.

Launch the online CAD editor

How to work with a DXF drawing

  1. Open Blackline CAD and use the available import command to select an ASCII DXF file.
  2. Check the file's drawing units and measure an existing line of known length before editing.
  3. Use line, polyline, circle, dimension and layer tools to edit the supported entities.
  4. Save a project copy; export to DXF and reopen it in another CAD application to check geometry and units.

What file compatibility means

DXF is an exchange format, but not every DXF uses only basic 2D entities. Blackline CAD supports a limited set of common ASCII DXF geometry. Some imports may omit advanced blocks, xrefs, splines, nonstandard hatches, layouts or proxy objects. Imported drawings with ambiguous units need manual verification.

DWG warning: direct binary DWG editing is not currently available through the public browser editor. Converting DWG files to supported DXF through an appropriate external tool may be necessary. Do not upload confidential construction files to an unverified conversion service.

For architecture and education

Use the editor to try basic architectural plans, technical drafting exercises, dimensions and layer organization. Check output in established CAD software before construction documentation or professional delivery.

Open DWG files and edit 2D DXF drawings online

Blackline CAD (CAD2D) is a browser-based 2D drafting editor. It supports opening DWG files through a configured conversion service, importing the resulting DXF drawing, editing compatible 2D geometry, layers and dimensions, and saving or exporting DXF. The editor is an independent developing product, not AutoCAD.

How to work with a DXF drawing

  1. Open Blackline CAD and select a supported DXF file, or choose a DWG file to be converted into DXF by the configured service (with your permission).
  2. Check the file's drawing units and measure an existing line of known length before editing.
  3. Use line, polyline, circle, dimension and layer tools to edit the supported entities.
  4. Save a project copy; export to DXF and reopen it in another CAD application to check geometry and units.

What file compatibility means

DXF is an exchange format, but not every DXF uses only basic 2D entities. Blackline CAD supports a limited set of common ASCII DXF geometry. Some imports may omit advanced blocks, xrefs, splines, nonstandard hatches, layouts or proxy objects. Imported drawings with ambiguous units need manual verification.

How DWG works: Blackline CAD accepts a DWG file and, when its configured converter is available, converts the file to DXF for editing inside the CAD2D workspace. Drawings are saved/exported as DXF rather than written back to native DWG. If the converter is unavailable or a DWG entity is unsupported, opening may fail or some geometry may not transfer. Check scale, layers and dimensions after conversion.

For architecture and education

Use the editor to try basic architectural plans, technical drafting exercises, dimensions and layer organization. Check output in established CAD software before construction documentation or professional delivery.
